계상 범위/남은 정책:
- IPC request: Tauri 소유, resource counter 밖. 거부 전 전체 copy 제거 VERIFIED.
- owned payload:512MiB 파일 한도로 간접 bounded; request와 동시에 존재 가능.
- ZIP input/parts: per-part256MiB/total1GiB/entries20k 유지, 두 package 동시 보유.
- UTF16: exact UTF8 allocation fallible, 부분 크기로 간접 bounded; 양쪽 decoded 문자열 보유.
- streaming text: 두 cursor32KiB 상한; 큰 attribute/comment/PI는 입력에 비례(별도 cap 없음).
- canonical header/statistics: vector/attr/atom/text capacity 직접 계상, production limit None.
- intern Arc headers/control blocks, hash buckets/control bytes/allocator rounding, parser scratch,
  reserve reallocation overlap은 retained payload에서 제외되어 중요한 과소계상이 가능하다.
- String/Vec try_reserve 일부 보강. CanonicalFailure::Allocation은 retained Vec 예약 실패만
  구별; parser/normalizer/Arc/BTreeMap 등의 abort/OOM은 회복 보장 불가. 일반 Invalid에는
  여전히 parser helper의 resource failure가 섞일 수 있다. IPC 예약 실패는 Internal이다.
- 동시 작업: 기존 DocumentState 공통8 operation 자리 및 세션별SaveTicket만 존재.
  자리는 blocking closure가 소유하여 future 취소로 조기 해제되지 않는다. payload는 자리
  획득 전 이미 복사될 수 있다. 글로벌 byte budget은 없다. 새 직렬화는 도입하지 않았다.
- publication: 검증 후 stage/write/readback/atomic publication, 실패/취소 guard cleanup.
  tempfile·원본 읽기 버퍼는 retained XML 계상 밖이며 실제 서비스 fault 회귀로 검증했다.
