구현과 귀속
기존 KoPub 판정은 각 glyph·문단에서 Unicode lowercase 문자열을 반복 생성했다.
CPU sampling은 이 경로의 Unicode 변환·할당을 관찰했고, 더 깊은 실제 span은 화학 문서16쪽
page-tree 비용 대부분이 body columns임을 보였다. 이름 판정은 영어 ASCII byte 검색으로
처리하고 기존 한글 literal 판정을 보존한다. Kelvin sign이 있으면 종전 Unicode lowercase로
돌아간다. 현재 Rust Unicode 표의 모든 scalar 및 영어 대소문자·경계·비ASCII 입력을
기존 predicate와 비교했다. 새 font 규칙·문서별 예외·캐시·전역 직렬화·예산 증가는 없다.

계측은 monotonic inclusive span/parent/job context를 기록한다. selfWallMs는 직접 자식
interval union을 빼므로 부모·자식을 CPU 합으로 중복 계산하지 않는다. 별도의500us CPU
sampling 수치와 무계측 wall time을 합치지 않는다. image.codec은 PNG가 주된 관찰이다.
처음 단계 이름만 보고 JPEG로 부른 해석을 교정했고 sampling 근거를 별도로 남겼다.
형상16쪽 layout과 PNG codec/upload는 각각 관찰된 비용이며 모든 native input 잔여 원인을
이 계측만으로 확정하지 않는다.
