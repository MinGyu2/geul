T010 decoded resource lease·회계 재현 절차

저장소 root에서 실행한다. 출력은 모두 새 경로로 쓴다. 기존 증거, external/, public/, 제품 소스는
수정하지 않는다. 공식 D4 MEASURE는 실행하지 않는다. 브라우저와 네이티브 실행은 하나씩 직렬로 한다.

도구(이번 실행): Rust 1.93.1(rustc 01f6ddf75), wasm-pack 0.15.0, wasm-bindgen 0.2.127, Chrome 155,
WebKitGTK 2.54.1 MiniBrowser + WebKitWebDriver, Xvfb 21.1.23, Python 3.14, Node 24.
이 호스트에서는 Rust 링크에 bfd가 필요하다. RUSTC_BFD는 rustc에 -C link-arg=-fuse-ld=bfd만 더하는
wrapper이고, CC_BFD 디렉터리의 cc는 원래 cc에 -fuse-ld=bfd만 더한다. compiler 설정은 바꾸지 않았다.

E=tests/integration/rhwp/evidence/t010-decoded-resource-lease-accounting
AE34=ae34 실험 패키지(WASM ae34c12b…7983, JS b69e920c…3252). manifest와 실제 bytes를 독립적으로 대조한다.

  accountingErrors=0, 선언 한도 불변을 다시 검증한다.
