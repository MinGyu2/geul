T010 준비 runtime 하드닝 계약

적용 범위: 명시적 setRendererPreparationEnabled(true)인 격리 Full 준비 job. 기본값 off와 호환 replay 경로는 바꾸지 않는다.

거부·종료 분류
- 준비 중 한 번 기록된 종료 사유(RESOURCE_LIMIT/ERROR/CANCELED)는 같은 poll의 뒤 단계가 덮지 않는다.
  record_prepared는 job이 Pending이 아니면 아무 표식 없이 false를 반환한다.
- 변환 memo 예약(job 32MiB, 모듈 64MiB) 거부는 RESOURCE_LIMIT이다. 거부 뒤 원본 fallback bytes를 decode하지 않는다.
  prepare_payload는 is_preparing()이 아니면 decode/브라우저 이미지 요청 없이 false를 반환한다.
- 거부 job은 ResourcesReady·replay·publication에 들어가지 않고, terminal 정리 후 준비 소유 bytes·decoded ledger·리소스가 0이다.

유지한 기존 계약(변경 없음)
- step 256 / resource operation 4 양자, MAX_KEYS 256, depth 64, node 65536, metadata 128KiB, job 32MiB, 모듈 64MiB.
- 15초 deadline, 공개 poll 결과 PENDING/COMPLETE/CANCELED/ERROR/RESOURCE_LIMIT.
- identity·generation 검사 지점, 원자 scratch publication, 기존 decoded lease/revoke/ledger 회계.

회귀 판정(hardening run.py가 브라우저 status를 믿지 않고 다시 판정)
control-small-watermark-complete, control-cleanup, large-source-fits-job-reservation, memo-refusal-is-resource-limit,
memo-refusal-transform-attempted, memo-refusal-no-decode-after-refusal, memo-refusal-no-ready-no-replay,
memo-refusal-not-published, memo-refusal-reservation-bounded, memo-refusal-cleanup 열 항목이 순서대로 모두 PASS여야 한다.
입력 파일(하네스·runtime.mjs·후보 js/wasm) SHA가 실행 전후 같아야 한다.

Rust 회귀
renderer::preparation::tests::direct_core_mutation_paths_and_failed_mutations: DerefMut을 우회하는 bookmark/hyperlink 직접
경로와 DPI/fallback 변경은 identity를 바꾸고, 거부된 편집은 바꾸지 않는다.

한계
