4. 해석
- VERIFIED(개입): `.rhwp-page`의 blur 그림자(--page-shadow: 0 1px 3px …, 0 8px 24px …)가 있으면 Canvas 갱신 뒤 프레임이 약 60 ms로 늘고,
  blur를 없애면(그림자 제거·blur 없는 그림자·outline) 같은 실행에서 editor key→frame p50 약 90 → 41 ms, p95 약 150 → 51–55 ms.
  3 px blur도 같은 비용이므로 blur 크기가 아니라 blur 그림자의 존재가 원인이다. 그림자를 다른 요소·독립 합성 레이어로 옮겨도 줄지 않았다.
- INFERRED: WebKitGTK 소프트웨어 합성에서 blur 그림자가 있는 영역의 손상 갱신이 매 프레임 blur 그리기를 다시 하거나 손상 영역을 넓힌다.
  WebKit 내부 단계는 측정하지 않았다(UNVERIFIED). 실제 GPU 데스크톱에서의 크기도 UNVERIFIED.
- 대조군의 부하(load 1.5–3.5)는 다른 세션이 있는 공유 호스트 값이다. 비교는 같은 실행 안의 섞인 블록끼리만 한다.
