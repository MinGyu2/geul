6. 불변식 (CONTRACT.ko.txt)
- 고유 = 상주 + 비상주(bytes, count). created − disposed = uniqueCount. 활성 job의 비상주 ≤ 96 MiB.
  고유 ≤ 캐시 예산 + 96 MiB. poll 경계 reserved = 0. accountingErrors = 0.
- commit: actual ≤ reserved만 성공하고, 실제 크기로 계상한다. 거절은 backing 1회 dispose, lease 없음,
  회계 불변이다. 할당 전 거절은 dispose 0이다.
- 메타데이터: job lease entry ≤ 256/job(≤ 2048 전체). registry ≤ 관측 live 최대값. 종료 뒤 0.
- bytes는 RGBA 추정이다. RSS, GPU, JS heap, decoder 임시 메모리의 상한이 아니다.
