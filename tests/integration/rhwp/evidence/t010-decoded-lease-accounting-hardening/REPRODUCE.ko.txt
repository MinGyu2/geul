T010 decoded lease 회계 보강 재현 절차

저장소 root에서 실행한다. 출력은 모두 새 경로로 쓰고, 기존 증거·external/·public/·제품 소스는 수정하지 않는다.
공식 D4 MEASURE는 실행하지 않는다. 브라우저와 네이티브 실행은 하나씩 직렬로 한다(빌드와 겹치지 않게).

도구(이번 실행): Rust 1.93.1(rustc 01f6ddf75; nixpkgs rustup 1.29.0으로 격리 RUSTUP_HOME에 minimal +
clippy/rustfmt/wasm32 설치), wasm-pack 0.15.0, Chrome 155, WebKitGTK 2.54.1 WebKitWebDriver,
Xvfb 21.1.23(nixpkgs#xvfb), tauri-driver 2.0.4(cargo registry 소스에서 --offline 설치), Python 3.14, Node 24.
이 호스트에서는 Rust host 링크에 bfd가 필요하다: CC_BFD 디렉터리의 cc는 원래 cc에 -fuse-ld=bfd만 더하고,
RUSTC_BFD는 rustc에 -C link-arg=-fuse-ld=bfd만 더한다. wasm 빌드에는 RUSTFLAGS를 주지 않는다.
