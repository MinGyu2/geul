GITLEAKS = pre-commit 환경의 gitleaks 8.30.1(.pre-commit-config.yaml rev v8.30.1).
- 전체 tree(dir): git archive HEAD를 빈 디렉터리에 풀고 .gitleaks.toml을 꺼낸 뒤
  GITLEAKS dir --redact --no-banner -c CONFIG . --report-format json --report-path OUT.json
  기본 규칙 비교는 -c 없이 같은 디렉터리를 검사한다(디렉터리 안에 .gitleaks.toml이 남아 있으면 자동으로 읽히므로 꺼낸다).
- 전체 이력(git): GITLEAKS git --redact --no-banner -c .gitleaks.toml --log-opts=--all --report-format json --report-path OUT.json .
- allowlist 음성 검사: python3 -I $R/repro/gitleaks_allowlist_negative_check.py --gitleaks GITLEAKS --config .gitleaks.toml --output OUT.json
git diff --check, 보호 경로·gitlink 확인(integrity.json).
